The gen generators.

Variants§

§

CrateMap

Crate map — workspace Cargo.tomls → crate/layer/purpose table (+ per-crate module sections when entry files exist). cypera.toml [crate_map] supplies layer overrides, the layer order, the default layer, splice targets, and the crate-api page.

Fields

§repo: PathBuf

Repo root (dir containing the workspace Cargo.toml). Default: current directory.

§config: Option<PathBuf>

Explicit cypera.toml path (default: discovered upward from --repo).

§out: Option<PathBuf>

Write a full page to this file instead of stdout. When the file exists and contains a <!-- crate-map --> marker, only the table after the marker is replaced. Overrides [crate_map] splices/crate_api.

§layers: Vec<String>

Layer override crate-name=layer (repeatable) — overrides [crate_map.layers] and the heuristic.

§

Cli

CLI reference — two modes:

  • --input <file|->: wrap gen-cli-docs markdown (clap-markdown) in a reference page.
  • otherwise: the docs/gen-cli-docs.py port — walk <bin> <prefix>… <sub>… --help recursively and emit the same page. The command spec comes from --package/--bin/ --prefix flags or [cli] in cypera.toml.

Fields

§repo: PathBuf

Repo root — cargo build + cypera.toml discovery base.

§config: Option<PathBuf>

Explicit cypera.toml path.

§input: Option<String>

gen-cli-docs markdown file, or - for stdin. When given, wrap mode (no help walk).

§package: Option<String>

Cargo package to cargo build -q -p first (config [cli].package fallback).

§bin: Option<String>

Binary under target/debug/ — or a PATH executable when --package is unset ([cli].bin).

§prefixes: Vec<String>

Argv prefix before the walked subcommand path, e.g. run for the driver run passthrough (repeatable; [cli].prefix fallback).

§title: Option<String>

Page title override ([cli].title fallback; default is the python scripts’ Command-Line Help for … header).

§skips: Vec<String>

Subcommand path to skip in the --help walk, space- joined (driver exec; repeatable; [cli].skip fallback).

§out: Option<PathBuf>

Write to this file instead of stdout ([cli].out fallback, then stdout).

§

Config

Config reference — two modes:

  • --file <rs>…: scan pub struct doc comments and render the generic page (--only/--title apply).
  • otherwise: the docs/gen-config-docs.py port — the curated [config] spec in cypera.toml (struct set, section titles, type vocabulary, prose sections).

Fields

§repo: PathBuf

Repo root — cypera.toml discovery + relative file resolution base.

§config: Option<PathBuf>

Explicit cypera.toml path.

§files: Vec<PathBuf>

Rust source file to scan (repeatable) — legacy mode.

§only: Vec<String>

Only document these struct names (repeatable). Legacy mode; in [config] mode filters struct sections.

§title: Option<String>

Page title. Legacy mode default: Config reference; [config] mode: overrides [config].title.

§out: Option<PathBuf>

Write to this file instead of stdout ([config].out fallback, then stdout).

§

Api

Rustdoc API site — the docs/gen-api*.py port: cargo doc --workspace --no-deps in the repo, the real target dir resolved via cargo metadata (respects a configured target-dir), <target>/doc copied into the docs site’s public/api/, and a styled crate index written to index.html. The output is a gitignored build artifact — check has nothing to freshness-gate. [api] in cypera.toml supplies out/prefix/title/ target_dir; every field is optional.

Fields

§repo: PathBuf

Repo root — the cargo doc/cargo metadata cwd. A <NAME>_ROOT env var (NAME = the cypera.toml dir’s basename, uppercased — the python TAMIAS_ROOT/ MYCO_ROOT/… convention) overrides it, which is how detached-sha doc pipelines point at the real checkout. Default: current directory.

§config: Option<PathBuf>

Explicit cypera.toml path (default: discovered upward from --repo).

§out: Option<PathBuf>

API output dir override — replaces [api].out/docs/public/api; a relative path resolves against the cwd (run from the docs worktree to land in a detached docs checkout, the python DOCS anchor).

§target_dir: Option<PathBuf>

Cargo target dir for the doc build — exported as CARGO_TARGET_DIR when unset ([api].target_dir fallback; the myco target/docs-api isolation).
