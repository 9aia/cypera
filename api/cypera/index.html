cypera — reusable documentation/reference generation for the 9aia org. The shared successor to the per-repo docs/gen-*.py scripts: one tool renders the crate map, CLI reference, and config reference pages every sibling docs site needs, driven by a per-repo cypera.toml discovered upward from --repo.

cypera gen crate-map [--repo <path>] [--config <path>] [--out <file>] [--layer <crate=layer>]…
cypera gen cli       [--repo <path>] [--config <path>] [--input <file|->] [--out <file>]
cypera gen config    [--repo <path>] [--config <path>] [--file <rs>]… [--out <file>]
cypera gen api       [--repo <path>] [--config <path>] [--out <dir>] [--target-dir <dir>]
cypera check         [--repo <path>] [--config <path>] [--json]

All generation logic lives in cypera-core (pure); this crate owns argv, cypera.toml discovery, filesystem walks, process spawning, and stdout.
