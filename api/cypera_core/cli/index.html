CLI-reference generation — two producers:

  • render_cli_page wraps gen-cli-docs markdown (the clap-markdown body sibling CLIs emit) in a page — the original cypera surface.
  • parse_help/render_help_walk are the pure half of the docs/gen-cli-docs.py port: clap --help text → structured nodes → the exact markdown those scripts emitted. The IO half (cargo build + process spawn) lives in cypera-cli.
