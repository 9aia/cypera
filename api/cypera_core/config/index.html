Source

Config-reference generation — scan Rust source for pub struct definitions and their /// doc comments, render the field table. Successor to the per-repo docs/gen-config-docs.py scripts, generalized: every pub struct in the input files is documented (no per-repo source map).

Pure string scanning — no parsing crate, no I/O. It understands exactly the doc-comment conventions the org’s config structs use: /// line docs on the struct and on pub fields, Option<…>/serde(default) ⇒ optional.
