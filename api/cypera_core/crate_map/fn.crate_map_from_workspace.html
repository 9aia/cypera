Expand description

Build a CrateMap from a parsed workspace manifest and the per-member crate manifests. members pairs each declared member path with its parsed manifest; entries optionally pairs member path → EntryScan. order is the [crate_map].order layer ranking (empty = DEFAULT_LAYER_ORDER); default_layer replaces the "adapter" guess fallback (None = "adapter").
