cypera.toml — the per-repo configuration that replaces the hardcoded knobs the per-repo docs/gen-*.py scripts carried (PKG/BIN/PREFIX/OUT, SRCS/TITLES/SIMPLE, LAYER/ ORDER/SITE, curated prose). Discovered upward from --repo (or the cwd); every section is optional.

[crate_map]
order = ["domain", "port", "adapter", "ops", "binary"]
default_layer = "impl"

[crate_map.layers]
"myco-core" = "domain"

[[crate_map.splices]]
target = "explanation/architecture.md"
marker = "<!-- crate-map -->"

[[crate_map.splices]]
target = "explanation/architecture.md"
first_table = true

[crate_map.crate_api]
site = "myco"
out = "reference/crate-api.md"

[cli]
package = "myco-driver"     # cargo -p to build (omit → `bin` on PATH)
bin = "tamias-driver-myco"   # binary under target/debug, or PATH name
prefix = ["run"]             # argv prefix before the engine argv
out = "reference/cli.md"     # optional emit target for `check`

[config]
title = "Config — `myco.toml`"
types = { "String" = "string", "PathBuf" = "path" }
field_types = { "aliases" = "{path: cuora://ref}" }
all_optional = ["Config"]
out = "reference/config.md"

[[config.structs]]
file = "crates/myco-core/src/lib.rs"
name = "Config"
title = "Top level"

[[config.sections]]
level = 2
title = "Constraints"
text = """
- `deny_unknown_fields`: typos fail the load.
"""

[api]                        # gen api — rustdoc site (optional)
out = "docs/public/api"      #   target/doc copy destination
prefix = "myco"              #   index filter + title base
target_dir = "target/docs-api"  # CARGO_TARGET_DIR when unset

[check]                      # cypera check — profile + exemptions
profile = "engine"           #   engine | library | content
skip = ["docs-site", "docs-check-script"]

Pure model + TOML decoding — the IO layer (discovery, file reads) lives in cypera-cli.

Structs§

ApiConfig
[api] — cypera gen api: cargo doc --workspace --no-deps in the repo, <target>/doc copied into the docs site’s public/api/, plus the styled crate index. Absorbs the per-repo docs/gen-api.py + docs/gen-api-index.py pair (and the inline docs:api shell bupha/kuda/mimus carried). The output is a gitignored build artifact — no check freshness.
CheckConfig
[check] — exemptions for cypera check. Rules named in skip are still evaluated but reported SKIP (exempt) instead of their computed status — for repos where a contract rule doesn’t apply by design: content-only ledger mounts, theme packages without the docs-worktree convention, the website repo itself.
CliConfig
[cli] — how to reach the CLI for the --help walk. Mirrors the PKG/BIN/PREFIX block every gen-cli-docs.py carried.
ConfigDocConfig
[config] — the config-reference page spec. Absorbs the SRCS/TITLES/SIMPLE/FIELD_LABEL/curated-prose blocks the gen-config-docs.py scripts hardcoded.
ConfigSection
A [[config.sections]] entry — heading + struct table or curated prose, in page order. title omitted renders the body with no heading (the bupha preamble convention).
ConfigStructRef
A [[config.structs]] entry — one pub struct to document.
CrateApiConfig
[crate_map.crate_api] — the rustdoc link list.
CrateMapConfig
[crate_map] — absorbs the per-repo LAYER/ORDER/SITE dicts and the <!-- crate-map -->/first-table splice targets the gen-crate-map.py wrappers hardcoded.
CrateMapSplice
One [[crate_map.splices]] entry — replace a crate-map table inside an existing page. Exactly one of marker/first_table must be set (validated by RepoConfig::validate).
RepoConfig
A decoded cypera.toml.

Constants§

CHECK_PROFILES
The docs-content profiles [check] profile accepts — the per-repo bar cypera check’s content rules enforce. engine is the full Diátaxis contract (tutorial + how-to + the explanation set + generated reference); library is the minimal bar (index + architecture + concepts); content is for narrative/site/ledger repos exempt from the quadrant requirements. Unknown values warn and fall back to engine.
CHECK_RULE_NAMES
The cypera check rule names — the vocabulary [check] skip accepts. Keep in sync with the rules constructed in cypera-cli/src/check.rs.
