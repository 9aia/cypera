cypera-xtask — workspace automation: check / test / coverage / pack / install / fmt.

cargo xtask check      # fmt --check + clippy -D warnings
cargo xtask test       # cargo nextest run (falls back to cargo test)
cargo xtask coverage   # llvm-cov report (extra args pass through)
cargo xtask pack       # stage libraries/cypera driver payload
                       # (release tamias-driver-cypera → drivers/bin/<triple>/)
cargo xtask install    # release-build tamias-driver-cypera → ~/.local/bin
cargo xtask fmt        # cargo fmt --all

host_triple 🔒
The host target triple — the drivers/bin/<triple>/ selector tamias uses for compiled driver payloads.
install 🔒
cargo xtask install — release-build tamias-driver-cypera and copy it to ~/.local/bin (idempotent, PATH-friendly name). The cypera cargo bin still exists for development, but the command users install ships as the tamias pack (cargo xtask pack + tamias install ./libraries/cypera); this installs the driver the shim resolves.
main 🔒
pack 🔒
cargo xtask pack — stage the tamias pack payload: release-build tamias-driver-cypera and drop it under libraries/cypera/drivers/bin/<host-triple>/ — the bundled-driver dir tamias install registers into <tamias-home>/drivers/. Gitignored on purpose: the binary is a build artifact; the committed pack is just tamias.yaml + this staging verb.
