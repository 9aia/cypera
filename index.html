What it is ​

Cypera is the org's reusable documentation generator: crate maps, CLI references, config references, rustdoc index pages, and the cypera check docs contract — rendered once for every sibling repo instead of per-repo gen-*.py scripts.

Why ​

Every 9aia docs site regenerates the same pages from the same sources. Per-repo scripts drifted; cypera kills the drift — one generator, one cypera.toml contract per repo, generated-not- handwritten as an enforced rule.

Boundary ​

  • Owns: reference-doc generation + the docs contract check.
  • Doesn't own: the docs sites themselves, gen-cli-docs producers, rustdoc internals, or any engine's ledger/coordination.
